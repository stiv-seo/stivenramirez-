## Notas generales de implementación

### Imágenes
- Todas con next/image para optimización automática
- Alt text descriptivo en todas las imágenes
- Formato WebP preferido
- Lazy loading automático con next/image

### Fuentes Google
- Preconnect en el <head>
- Fuentes cargadas con next/font/google
- Solo los pesos necesarios

### Animaciones
- Framer Motion para scroll animations
- CSS transitions para hover states
- IntersectionObserver para counters de stats

### Mobile
- Todo diseñado mobile-first
- Header con hamburger menu en < 768px
- Grid de 2 columnas → 1 columna en mobile
- Botones full-width en mobile cuando están en stack
